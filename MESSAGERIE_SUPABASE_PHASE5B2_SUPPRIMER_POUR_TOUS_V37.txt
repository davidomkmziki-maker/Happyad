HAPPYAD V37 — MESSAGERIE SUPABASE — PHASE 5B2
SUPPRIMER POUR TOUS
Date : 2026-07-11
Base : Phase 5B1A validée

OBJECTIF
Ajouter « Supprimer pour tous » sans modifier les autres modules ni ajouter une seconde confirmation.

COMPORTEMENT
- Appui long sur un message reçu : « Supprimer pour moi » uniquement.
- Appui long sur son propre message : « Supprimer pour moi » et « Supprimer pour tous ».
- Le premier popup est la seule confirmation.
- « Supprimer pour tous » appelle public.happyad_msg_delete_for_all avec p_message_id.
- Seul l’expéditeur peut déclencher cette action dans l’interface.
- Le contenu devient immédiatement « Message supprimé ».
- Le texte, le vocal, la photo, la vidéo et le fichier sont retirés de la bulle.
- Les réponses qui citaient ce message affichent « Message supprimé ».
- La liste des conversations affiche « Message supprimé » lorsque ce message est le dernier.
- L’événement Realtime UPDATE de happyad_msg_messages applique la suppression chez l’autre compte.
- En cas d’erreur Supabase, l’état précédent est restauré.

STABILITÉ
- Réponse par glissement conservée.
- Blocage de la sélection Google conservé.
- Supprimer pour moi conservé.
- Aucun SQL ajouté.
- Aucun autre module modifié.
