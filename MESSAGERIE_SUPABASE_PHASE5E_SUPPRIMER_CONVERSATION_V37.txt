HAPPYAD V37 — MESSAGERIE SUPABASE — PHASE 5E
SUPPRIMER UNE CONVERSATION POUR MOI

Base conservée : Phase 5D validée.

Ajouts :
- Le menu à trois points de la conversation contient maintenant :
  1. Supprimer tous les messages pour moi
  2. Supprimer la conversation
  3. Annuler
- Un seul popup suffit : aucun deuxième écran de confirmation.
- « Supprimer la conversation » retire immédiatement la conversation de la liste du compte connecté.
- L'autre personne conserve sa conversation et ses messages.
- Les anciens messages sont aussi effacés pour le compte qui supprime la conversation.
- La suppression est persistante sur les autres appareils du même compte.
- Si un nouveau message arrive après la suppression, la conversation réapparaît automatiquement avec seulement les nouveaux messages.
- Une conversation sans message peut également être supprimée.
- En cas d'échec Supabase, le chat affiché est restauré.

SQL ajouté :
- Colonnes membres : deleted_through_seq, conversation_deleted_at
- RPC : happyad_msg_delete_conversation_for_me(p_conversation_id uuid)
- RPC : happyad_msg_list_conversation_deletions()

Realtime :
- Aucun nouveau canal ni nouvelle table.
- La table happyad_msg_conversation_members déjà active en Realtime transporte l'état de suppression.
