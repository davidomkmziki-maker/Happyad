HAPPYAD V37 — PHASE 5E1
RÉOUVERTURE APRÈS SUPPRESSION DE CONVERSATION

Correction appliquée :
- après « Supprimer la conversation », les anciens messages restent masqués pour ce compte ;
- si ce compte envoie ensuite un nouveau texte, vocal, fichier, photo ou vidéo, la conversation réapparaît immédiatement dans sa liste ;
- la conversation réapparaît aussi chez un membre qui l'avait supprimée lorsqu'un nouveau message lui arrive ;
- le nouveau message devient le premier message visible de la nouvelle vue locale ;
- aucun ancien message supprimé pour ce compte n'est restauré ;
- chez l'autre personne, la conversation originale continue normalement avec tout son historique.

Supabase :
- nouveau trigger sur happyad_msg_messages après INSERT ;
- conversation_deleted_at est remis à NULL uniquement lorsqu'un message plus récent que deleted_through_seq existe ;
- deleted_through_seq reste intact afin de préserver la séparation avec l'ancien historique.

Frontend :
- l'état local de conversation supprimée est retiré seulement après confirmation d'un nouvel envoi ;
- actualisation immédiate de la liste pour les textes et tous les médias.

Base conservée : Phase 5E validée.
