HAPPYAD V37 — MESSAGERIE SUPABASE PHASE 5G3
VOCAL ET AUDIO EN VUE UNIQUE

BASE
- HAPPYAD_P1_V37_MESSAGES_SUPABASE_PHASE5G2_VIDEO_VUE_UNIQUE.zip

AJOUTS CIBLÉS
- vue unique pour les vocaux enregistrés dans HAPPYAD ;
- vue unique pour les fichiers audio compatibles sélectionnés depuis le téléphone ;
- bulle minimale : œil SVG + « Vocal » ou « Audio » ;
- lecteur audio interne sans lien de téléchargement ;
- le clic d’ouverture ne consomme pas le contenu ;
- consommation au premier démarrage réel de la lecture ;
- fermeture avant lecture : réservation libérée, contenu encore ouvrable ;
- fermeture après démarrage ou fin de lecture : disparition en poussière chez le destinataire ;
- chez l’expéditeur : « Déjà ouvert » / « Toucher pour nettoyer » ;
- aucune URL audio vue unique dans le cache média permanent ;
- aperçu de conversation recalculé depuis le dernier message encore visible.

NON MODIFIÉ
- texte vue unique : réservé à la Phase 5G4 ;
- PDF/documents vue unique : réservés à la Phase 5G5 ;
- photo 5G1 et vidéo 5G2 ;
- profils, Radar, Boutique, notifications, authentification et autres modules.

INSTALLATION
1. Exécuter SUPABASE_HAPPYAD_MSG_PHASE5G3_AUDIO_VUE_UNIQUE.sql.
2. Vérifier PHASE_5G3_AUDIO_VIEW_ONCE_OK.
3. Déployer le ZIP Phase 5G3.
4. Tester avec deux comptes et deux téléphones.
