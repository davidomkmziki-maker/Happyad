HAPPYAD — MESSAGERIE SUPABASE PHASE 4A AUDIO RÉEL
Base : HAPPYAD_P1_V37_MESSAGES_SUPABASE_PHASE3B_READ_VISIBLE_ONLY.zip
Date : 2026-07-11

PORTÉE STRICTE
- Audio uniquement.
- Aucun changement sur photo, vidéo, fichier, vue unique, suppression ou réponse.
- Aucun changement sur Profil, Profil visiteur, Radar, Boutique, Auth ou PWA hors version du cache.
- Aucun ancien système Messages réintroduit.

CONNEXION AUDIO
- Enregistrement réel avec MediaRecorder et microphone du téléphone.
- Premier appui sur le micro : démarrer l’enregistrement.
- Deuxième appui : arrêter puis envoyer.
- Minuteur visible pendant l’enregistrement.
- Durée maximale automatique : 5 minutes.
- Refus des enregistrements vides ou trop courts.

STORAGE
- Bucket privé : happyad-message-files.
- Chemin canonique : conversation_id/sender_id/client_message_id/audio.extension.
- Types privilégiés : audio/webm;codecs=opus, audio/webm, audio/ogg;codecs=opus, audio/mp4.
- En cas d’échec de la RPC après upload, tentative de suppression du fichier orphelin.

RPC UNIQUE
- public.happyad_msg_send_media
- kind = audio
- duration_ms obligatoire
- caption = NULL
- view_once = false
- aucune insertion directe dans les tables.

AFFICHAGE
- Le vocal reste un vrai audio, jamais le texte « Message vocal ».
- Lecteur vocal dans la bulle existante : lecture/pause, progression et durée.
- Les fichiers privés sont lus avec une URL signée Supabase temporaire.
- Le message local en attente est remplacé par le message serveur confirmé grâce à client_message_id.
- Realtime récupère le message complet avec happyad_msg_list_messages afin d’obtenir la pièce jointe.

FICHIERS MODIFIÉS
- modules/message-center.html
- service-worker.js
