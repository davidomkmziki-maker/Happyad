# HAPPYAD V818 — Éditeur de médias d’annonce professionnel

Base : V817.

## Corrections ciblées

- Une seule zone publique pour ajouter les photos et vidéos de l’annonce.
- Suppression des trois commandes d’ajout répétées de la V817.
- Le sélecteur principal disparaît après le premier média ; un seul bouton « Ajouter un média » reste disponible.
- Galerie professionnelle en cartes 4:5 avec numéro, type de média et indication de la couverture.
- La première photo ou vidéo devient clairement la couverture de l’annonce.
- Une photo se modifie avec un seul bouton « Modifier » ; la suppression utilise une icône dédiée.
- Un toucher sur la carte ouvre toujours l’aperçu plein écran.
- Prévisualisation renforcée : une URL locale est recréée une fois si le navigateur perd l’aperçu.
- En cas de format non prévisualisable, aucun pictogramme d’image cassée n’est affiché : une carte propre indique que le fichier reste sélectionné.
- Même protection pour l’aperçu compact, le plein écran et les justificatifs privés.
- Les justificatifs restent séparés et privés ; seuls les médias de la galerie sont publics.

## Installation

Aucun SQL n’est requis. Déployer seulement le ZIP V818, fermer complètement l’ancienne page et rouvrir HAPPYAD afin de charger le Service Worker V818.
