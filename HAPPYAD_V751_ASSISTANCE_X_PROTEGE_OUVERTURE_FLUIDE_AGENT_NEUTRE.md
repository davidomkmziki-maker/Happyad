# HAPPYAD V751 — Assistance X protégé, ouverture fluide, agent neutre

- Le X reste au-dessus de la page précédente jusqu’à la fin complète du geste Android.
- Aucun clic synthétique ne peut atteindre Paramètres, Messages ou Profil derrière l’Assistance.
- L’Assistance est préchauffée plus tôt et n’est révélée qu’après READY ; le chargement visible n’apparaît qu’en secours après 190 ms.
- L’annonce de connexion ne contient plus le nom de l’agent : message professionnel neutre dans les dix langues.
- Les anciennes annonces nominatives déjà stockées sont neutralisées à l’affichage.
