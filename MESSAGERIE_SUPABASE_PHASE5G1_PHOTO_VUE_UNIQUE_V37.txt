HAPPYAD V37 — MESSAGERIE SUPABASE PHASE 5G1 PHOTO VUE UNIQUE

Base exclusive : HAPPYAD_P1_V37_MESSAGES_SUPABASE_PHASE5F1_RESPONSIVE_BLOCK_COMPOSER.zip

Fichiers modifiés :
- modules/message-center.html
- service-worker.js (version de cache uniquement)
- README.md

SQL ajouté :
- SUPABASE_HAPPYAD_MSG_PHASE5G1_PHOTO_VUE_UNIQUE.sql

Comportement :
- la vue unique est activable seulement pour une photo ;
- l’expéditeur ne voit jamais et ne rouvre jamais sa propre photo après l’envoi ;
- le destinataire réserve l’ouverture avec happyad_msg_claim_view_once ;
- un échec avant décodage de l’image libère la réservation et ne consomme pas la photo ;
- après décodage réel, happyad_msg_consume_view_once_internal rend toute deuxième ouverture impossible ;
- au clic ×, la bulle destinataire disparaît avec l’animation poussière ;
- chez l’expéditeur, la bulle devient « Message ouvert » ;
- cette bulle disparaît en poussière seulement si l’expéditeur la touche ;
- les disparitions sont enregistrées dans happyad_msg_message_access et synchronisées en Realtime ;
- aucune URL signée de vue unique n’est mise dans signedMediaCache ;
- les réponses affichent « Réponse à un message en vue unique » sans révéler le contenu.

Non modifié :
- texte vue unique ;
- vidéo vue unique ;
- vocal/audio vue unique ;
- PDF/document vue unique ;
- profils, boutique, Radar, publications, notifications et authentification.
