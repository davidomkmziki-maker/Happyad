# HAPPYAD V693 — Miniature globale immédiate

Base: V692.

Cette version corrige la propagation de la miniature choisie par le créateur vers l'Accueil et élimine le flash noir résiduel dans les profils. Le parent principal charge désormais le maître de synchronisation, les objets en mémoire et caches sont corrigés immédiatement, et l'URL officielle choisie est prioritaire sur les anciennes miniatures noires.

Aucun SQL supplémentaire.
